# Dziennik makro

Prosta aplikacja na telefon do zapisywania:

- kalorii i makroskładników (białko, tłuszcz, węglowodany, cukry, błonnik, sól),
- wagi ciała i zapotrzebowania kalorycznego,
- treningów: kalendarz, intensywność, ćwiczenia z seriami i postępy.

Działa w przeglądarce i można ją dodać do ekranu głównego telefonu. Dane zapisują się tylko na urządzeniu (w pamięci przeglądarki), nic nie trafia na serwer. Kopię danych zrobisz w aplikacji: „Kopia zapasowa” → „Kopiuj wszystkie dane”.

## Pliki

- `index.html`: cała aplikacja (wygląd i działanie)
- `manifest.webmanifest`: nazwa, kolory i ikonka po dodaniu do ekranu głównego
- `sw.js`: zapamiętuje pliki, żeby aplikacja działała bez internetu
- `icon-*.png`, `apple-touch-icon.png`: ikonki

Strona jest hostowana za darmo przez GitHub Pages z gałęzi `main`.
